┌─────────────────────────────────────────────────────────────┐
│ STEP 1: Start Backend (Terminal 1)                         │
└─────────────────────────────────────────────────────────────┘

  cd /home/npc/YO
  source venv/bin/activate
  python main.py

  ✅ Should see: "Application startup complete"
  ✅ Backend running on: http://localhost:8000


┌─────────────────────────────────────────────────────────────┐
│ STEP 2: Start Frontend (Terminal 2)                          │
└─────────────────────────────────────────────────────────────┘

  cd /home/npc/YO
  source venv/bin/activate
  streamlit run app.py

  ✅ Browser opens: http://localhost:8501


┌─────────────────────────────────────────────────────────────┐
│ STEP 3: Demo Traditional Method (Bbox-based)                │
└─────────────────────────────────────────────────────────────┘

  1. Select template: "सम्पत्ति तथा भूमिकर फारम"
  2. Upload: templates/business_front.jpg
  3. ❌ Leave "Use Semantic Matching" UNCHECKED
  4. Click "🔍 Run OCR"
  5. Show extracted fields
  6. Click "✅ Validate & Save"
  7. Download PDF

  💡 Explain: "Uses predefined bounding boxes from template"


┌─────────────────────────────────────────────────────────────┐
│ STEP 4: Demo Semantic Matching (NEW FEATURE)               │
└─────────────────────────────────────────────────────────────┘

  1. Select template: "सम्पत्ति तथा भूमिकर फारम"
  2. Upload: ID card image (or any document)
  3. ✅ CHECK "🧠 Use Semantic Field Matching"
  4. Click "🔍 Run OCR"
  5. Show matched fields (e.g., "नाम : हसन गाहा" → "जग्गा/धनीको नाम र थर")
  6. Click "✅ Validate & Save"
  7. Download PDF

  💡 Explain: "Intelligently matches fields without bounding boxes"


┌─────────────────────────────────────────────────────────────┐
│ KEY TALKING POINTS                                           │
└─────────────────────────────────────────────────────────────┘

  ✓ Problem: Traditional OCR needs exact bounding boxes
  ✓ Solution: Semantic matching understands field labels
  ✓ Features: Keyword dictionaries, fuzzy matching, confidence scoring
  ✓ Use Case: ID cards, certificates, unstructured documents
  ✓ Technology: rapidfuzz, Nepali language support, category matching


┌─────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                              │
└─────────────────────────────────────────────────────────────┘

  Backend won't start?
    → Check port 8000: lsof -i :8000
    → Check logs in terminal

  Streamlit can't connect?
    → Verify backend is running
    → Check sidebar URL: http://localhost:8000

  No templates showing?
    → Check templates/*.json files exist

  OCR errors?
    → Verify: tesseract --version
    → Check: ls tessdata/nep.traineddata
